Скрипт для автоматической проверки на свободный слот для записи для сдачи на права через Госуслуги. 
Работает через прямое API Госуслуг, умеет самостоятельно обновлять авторизационную сессию через headless-Chromium и отправлять push-уведомления на телефон через [ntfy.sh](https://ntfy.sh).

Для отправки уведомлений на мобильный телефон используется приложение ntfy. Его можно скачать по ссылкам ниже:
[![App Store](https://img.shields.io/badge/App_Store-0D96F6?style=for-the-badge&logo=app-store&logoColor=white)](https://apps.apple.com/app/ntfy/id1625396347)
[![Google Play](https://img.shields.io/badge/Google_Play-414141?style=for-the-badge&logo=google-play&logoColor=white)](https://play.google.com/store/apps/details?id=io.heckel.ntfy)


## Как его использовать?
### Вариант 1. Через uv (рекомендуется)
1. **Клонируйте репозиторий**
    ```bash
   git clone https://github.com/poseidk/gu-autocheck.git
   cd gu-autocheck
    ```
    
2. **Запустите мастер первичной настройки и нажмите 5**
    ```bash
    uv run master.py
    ```
_примечание, при вставке текст не отображается_

3. **Запустите скрипт**
   ```bash
   uv run checker.py
   ```
  
### Вариант 2. Через pip
1. **Клонируйте репозиторий и создайте виртуальное окружение:**
  ```Bash
  git clone https://github.com/poseidk/gu-autocheck.git
  cd gu-autocheck
  python -m venv .venv
  source .venv/bin/activate  # На Windows: .venv\Scripts\activate
  ```
2. Установите зависимости:
  ```Bash
  pip install -r requirements.txt
  ```
3. **Запустите мастер первичной настройки и нажмите 5**
  ```Bash
  python master.py
  ```
4. **Запустите скрипт**
  ```bash
  python checker.py
  ```

### Возможности и управление
1. Во время работы основного скрипта(checker.py) прямо в терминале доступны горячие клавиши:
  - c — мгновенно выполнить принудительную проверку слотов;
  - r — перезапустить сессию и обновить куки;
  - q — безопасно завершить работу.
2. Авто-обновление сессии: в веб версии Госуслуг ваши куки живут ~4 часа, поэтому скрипт автоматически проходит аутентификацию и обновляет их, и продолжает работу без вашего участия.

### Безопасность и конфиденциальность
- **Локальное хранение**: Все учётные данные (`config.json`) и сессии (`cookies.json`) хранятся исключительно на вашем устройстве.
- **Никаких сторонних серверов**: Скрипт работает полностью локально и взаимодействует напрямую только с API Госуслуг и вашим сервисом ntfy.
